# 꼬마 슈팅 놀이터

아이를 위한 터치 슈팅 놀이터. 한 번 설치하면 인터넷 없이 실행됩니다.

## 아이패드 / 아이폰에 설치
1. **Safari**로 GitHub Pages 주소를 엽니다.
2. **공유 → 홈 화면에 추가**를 누릅니다.
3. 인터넷이 켜진 상태에서 홈 화면 아이콘으로 한 번 실행합니다. 이후에는 오프라인에서도 됩니다.

## 수정할 때
파일을 바꾼 뒤 `sw.js`의 `VERSION`을 올려야 설치된 기기에 새 버전이 반영됩니다.

## 업데이트 내역

### 2026-11-17
- 3D 놀이를 놀이 방식이 서로 다른 9개로 새로 만들었습니다. 기존 3D 놀이와 우주 젤리(외계인) 맵은 뺐습니다.
  - **3D 두더지 뿅뿅**: 계단식 밭 구멍에서 튀어나오는 모자 쓴 두더지 맞히기. 가끔 두더지 대소동
  - **3D 하늘 비행**: 비행기를 타고 날아가며 다가오는 풍선 터뜨리기. 먹구름은 피하기
  - **3D 배고픈 공룡**: 걸어오는 공룡 네 종류에게 과일을 던져 먹이기
  - **3D 꼬마 기차**: 모형 철도를 달리는 기차 칸 위 선물상자 맞히기
  - **3D 곤충 정원**: 나비·벌·무당벌레·잠자리를 비눗방울로 잡기. 말벌은 피하기
  - **3D 비눗방울 바다**: 떠오르는 방울 속 물고기·복어·문어를 꺼내주기
  - **3D 해적선**: 파도 위 해적선 돛을 맞혀 흰 깃발 올리게 하기
  - **3D 불꽃놀이**: 밤하늘로 올라가는 로켓을 맞혀 불꽃 터뜨리기
  - **3D 사탕 피냐타**: 흔들리는 피냐타를 터뜨려 사탕 비 내리기
